# Alchemist’s Cauldron

The game is a task from the Rolling Scopes School Short track course. [See the original task description.](https://github.com/rolling-scopes-school/qualifying-stage/blob/main/tasks/game-alchemists-cauldron/README.md)

This is a pure TypeScript project, without frameworks or libraries.

## About the game

Brew your potion!

> The goal of the game is to match 3 target ranges (_temperature_, _density_ and _magic power_) before time or lives run out.

## The structure of the task

The task is designed to challenge everyone. There are levels (stories) with increasing implementation difficulty, and students can choose to stop at any level. Each level builds on the previous one; students cannot skip a level.

### Precondition

The Precondition covers repository setup, project setup and the technical base.

### Level 1: Basic

Completing Level 1 gives one full playable game with one fixed ruleset.

### Level 2: Extended

Level 2 adds a difficulty selection and save / continue feature.

### Level 3: Full game

Level 3 adds more advanced features, such as drag & drop, tooltip, reactions, Pour Out, keyboard shortcuts and visual feedback.

## How to run the game

You can play the game online:

[Play the game](https://schemingcate.github.io/alchemists-cauldron/)

If you’d like to run it locally, execute these commands in the terminal:

```bash
git clone -b story-1 https://github.com/SchemingCate/alchemists-cauldron.git
cd alchemists-cauldron
npm i
npm run dev
```
